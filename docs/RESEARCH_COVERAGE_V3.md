# V3 parameter surfaces, aligned cohorts and shared gate

26 legacy OHLCV families now have explicitly variable window, auxiliary
window, smoother, price input, threshold, comparator (where meaningful).
Five existing dedicated multi-parameter families retain their contracts.
Not every option affects every formula: a parameter with no mathematical
role is not a new independent indicator. No exhaustive real-valued search.

One active cohort per market: sixteen deterministic registered variants,
all measured on identical completed calendar weeks; no winner-only PBO.
Discovery-only selection, separate retrospective validation, real aligned
weekly net paths, approximate DSR with conservative total recorded trial
count. PBO/DSR remain retrospective, not evidence of independent forward alpha.
Superlab independently recomputes the panel metrics and blocks promotion.
Each selected definition is frozen; observe 90 genuinely new daily bars,
verify every previously observed bar by fingerprint, refuse on source/code
changes. No orders. No paper approval. Cohorts are bounded to 24 per market;
ordinary research remains continuous. Source price proxy/borrow limitations
remain. Seven independent workflow families now call a common pinned report
gate; source/design-only inputs cannot be declared qualified. Unknown report
schemas are explicitly blocked. This is evidence classification, not full
independent re-execution from all vendor inputs. No new paid sources or cron.
