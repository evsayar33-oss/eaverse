# Coverage debt V1 (research only)

The existing autonomous research / PAPER rules are unchanged. On each asset already
loaded by the main engine, a separate version performs one real retrospective
experiment per registered lane and timeframe (maximum ten per asset visit).
The existing SQLite checkpoint and archive preserve trial identities and results.
The report exposes completed/registered and explicit data/runtime-blocked states.
A missing source or short history does not move its cursor. No trial is selected
for PAPER, Superlab ACCEPT, or live trading by this layer.

Coverage: 16 legacy signal families plus 10 numeric families, fixed registered
settings, percentage/z-score/rolling volume-weighted price proxy, two comparison
directions plus crossing for numeric signals, pair and sparse 3–5-way synthesis,
calendar and known-date macro gates, 1d/1w, long/short/long-short, state/confirmation/
fixed-horizon entry modes, three sizing models. Costs doubled; short borrow is
an assumption, not actual locate or derivatives funding. No tick, order-book,
intrabar fill, holder cost basis, or publication-vintage claim. Weekly uses only
interior completed weeks from already validated daily source bars. Each fold is
retrospective. No PBO/DSR is claimed for this new grid.

A finite registered grid is not all mathematically possible strategies. Pair
and synthesis templates use representative settings, not their full Cartesian
product. Macro cursor may remain blocked until its specific event data becomes
usable. The queue only reaches assets visited by the existing universe and
runtime scheduler. 1m–4h and other markets, full source-native event combinations,
stop/TP execution, multi-asset portfolios, adaptive optimization and aligned
return-path evidence remain separate expansion work. No fabricated coverage.
